How to connect real Google Login?
  1. Go to the Google Cloud Console.
  2. Create a project and go to Credentials.
  3. Create an OAuth Client ID for a Web Application.
  4. Add http://localhost:5173 to Authorized JavaScript origins and redirect URIs.
  5. Add VITE_GOOGLE_CLIENT_ID=your_id_here in your project's .env file.
